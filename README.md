# Проверка честности раунда

Здесь лежит **страница**, которая открывается в браузере и показывает, что итог раунда PvP-рулетки **совпадает с тем, что было заранее «зашито» в хэш** — без доверия к нам на слово: пересчёт идёт **у вас на устройстве**, страница к игровому серверу не обращается.

---

## Что вы увидите

Откройте опубликованную ссылку (например, страницу на GitHub Pages) — откроется одна страница с коротким объяснением, полями с данными раунда и кнопкой **«Проверить честность»**.

- Если вам прислали **ссылку с раундом** — откройте её: поля заполнятся сами, нажмите кнопку проверки.
- Если ссылки нет — нажмите **«Загрузить пример»**, чтобы увидеть, как это выглядит на готовом раунде.
- После успешной проверки появится сообщение, что раунд **честный**; ниже можно посмотреть **тот же код**, который всё посчитал (ничего подгружать с интернета не нужно — только эта страница).

---

## Как пользоваться

1. Откройте страницу по ссылке, которую вам дали (или с главной сайта проекта, если там есть кнопка «Проверить честность»).
2. Убедитесь, что заполнены поля раунда (обычно они уже подставлены из ссылки).
3. Нажмите **«Проверить честность»** и дождитесь результата.

Чтобы **поделиться раундом** с другим человеком: на странице нажмите **«Скопировать ссылку с раундом»** и отправьте полученную ссылку — у получателя откроется та же проверка с теми же данными.

---

## Важно знать

- Работает в обычном современном браузере; страницу лучше открывать по **https** (так надёжнее включается встроенная криптография).
- Страница **ничего не отправляет** на игровой сервер — только показывает данные и пересчитывает их у вас в браузере.

Если что-то не открывается или проверка не проходит — напишите в поддержку проекта и приложите **ссылку**, которую вы открывали, или скриншот.
