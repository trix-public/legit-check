# Проверка честности раунда

Статическая страница и открытый репозиторий с тем же кодом, что в браузере пересчитывает честность завершённого раунда PvP-рулетки. Страница **не обращается к игровому серверу**: достаточно данных раунда из ссылки (`#d=…`) или вставленных в поля вручную.

- Сайт: [legit-check на GitHub Pages](https://trix-public.github.io/legit-check/)
- Логика проверки: [`scripts/legit-check.js`](scripts/legit-check.js) (тот же файл показан на странице)
- Локально: из корня репозитория — любой static server, например `python3 -m http.server 8081`

На странице: краткое объяснение, сводка по раунду, участники (с диапазонами секторов партий), поля для проверки, результат пересчёта, FAQ и исходник скрипта.

---

## Простыми словами

1. **Пока раунд идёт** — в игре видны короткие отпечатки (хэши). **client_commit_hash** (отпечаток итога) пересчитывается после каждой ставки и трика: в расчёт входят актуальные данные раунда. **salt_hash** (отпечаток соли) **не меняется**: соль задаётся один раз и даёт «рандом»; до финиша виден только её хэш, не сама соль. Имеет смысл **скопировать salt_hash** с экрана раунда — для проверки после финиша.

2. **Итог раунда** — число на колесе **от 0 до 99 999**. Его не выбирают отдельно: из **текста всех данных раунда** и **раскрытой соли** считают **commit_hash**, из него по фиксированной формуле — позицию на колесе. Побеждает сторона, в чей сектор попало это число.

3. **После раунда** публикуют секреты: полный текст данных (ставки, участники, секторы), соль и **финальные** хэши (`commit_hash`, `client_commit_hash`). На странице проверки поля заполняются автоматически из ссылки — сверьте с тем, что видели в игре (особенно **salt_hash**, если сохраняли).

4. **Почему это работает** — финальные данные, соль и хэши либо сходятся по формулам, либо проверка сразу падает; подменить исход задним числом не выйдет. Пересчёт идёт **в вашем браузере**, код открыт.

---

## Как устроен алгоритм и «рандом»

**Пока раунд идёт** — отпечатки без полных данных и соли. Текст данных раунда растёт (ставки, трики), **commit_hash** и **client_commit_hash** обновляются. **salt_hash** постоянен.

**После финиша** — раскрытие: текст данных (`fairness_preimage`, одна UTF-8 строка как отдал сервер), **salt** в base64, финальные **commit_hash** и **client_commit_hash**.

### Соль и salt_hash

- **salt** — секретная случайная добавка, **одна на весь раунд**, не меняется.
- **salt_hash** = `SHA-256(байты salt)` (на сервере — `MaskBytes`). Показывают в живом раунде; при новых ставках **не меняется**.
- После раскрытия проверка **salt_hash + salt** подтверждает, что отдали ту же соль, что была с начала катки.

### Отпечатки итога

- **commit_hash** = `SHA-256(байты fairness_preimage ‖ байты salt)` — отпечаток **финального** снимка данных + соли.
- **client_commit_hash** = `SHA-256(commit_hash)` — короткая «маска», в игре обновляется вместе с commit, пока меняется состав раунда.

Под «отпечатком» везде имеется в виду **SHA-256** (32 байта, в API часто в base64).

### Шаги проверки (как на странице)

1. Если указан **salt_hash** — `SHA-256(байты salt)` должен совпасть с ним (соль не подменили).
2. Из **финального** текста данных и **salt** получают **commit_hash**; сравнивают с опубликованным.
3. От **финального commit_hash** считают **client_commit_hash**; сравнивают с финальным из результата раунда.
4. Из **commit_hash** выводят число **0…99 999** (первые 8 байт как big-endian, остаток по модулю 100 000); при желании сверяют с `roulette_position`.
5. По позиции и секторам партий (`sector_from` … `sector_to`) определяют победителя.

Любой сломанный шаг — проверка не проходит.

**Итого:** salt_hash фиксирует соль на весь раунд; финальные commit и client_commit должны сойтись с пересчётом; раскрытые данные + соль задают позицию на колесе.

## Почему этому можно доверять

- Код проверки **открыт** в репозитории; на странице показан **тот же** `legit-check.js`, который выполняется по кнопке «Проверить честность».
- Сайт на **GitHub Pages** — содержимое отдаётся из этого репозитория; отдельную закрытую версию скрипта «только для сайта» не подмешать.
- Пересчёт **у вас в браузере**; `fairness_preimage` для проверки **нигде не отправляется**.
- Если что-то не сходится — напишите в **чат поддержки** (ссылка на раунд или данные из полей).
